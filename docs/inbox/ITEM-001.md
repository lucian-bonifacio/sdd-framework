# Avaliar integração opcional com AI Memory

## Informação ou proposta
Investigar AI Memory como recuperação de conhecimento entre agentes e sessões.
O usuário pediu explicitamente manter a proposta na INBOX quando o projeto fosse
criado. Não é dependência nem requisito aprovado de integração.

## Fontes
- Conversa de concepção do SDD Framework, consultada em 2026-11-06.
- [Repositório AI Memory](https://github.com/akitaonrails/ai-memory), README consultado em 2026-11-06.
- [Workflow Akita](https://ailair.akitaonrails.com/pt-br/workflow/), consultado em 2026-11-06.

## Impacto e discussão
Avaliar custo de operação, captura, privacidade, interoperabilidade e mecanismos
para não tratar memória como requisito aceito. CHECKPOINT e INBOX devem continuar
funcionando sem serviço. Decidir futuramente se adaptador opcional tem utilidade
concreta e como referenciar fontes sem duplicar documentos governados.

## Destino ou justificativa
Pendente de avaliação. Não incorporar automaticamente ao roadmap de implementação.
